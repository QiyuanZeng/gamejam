# 《时间刺客》程序执行方案（数值确定版）

> 版本：v1.0
> 配套文档：《时间刺客-详细策划文档》v0.2（下称 GDD）
> 本文档定位：程序实现唯一依据。**所有数值无歧义，可直接照写。**
> 数值来源规则（已确认）：
> 1. **GDD 已写明的数值 → 以 GDD 为准**（即使与现有原型代码冲突，改代码）。
> 2. **GDD 未写的数值 → 优先沿用现有原型代码常量**（`scripts/main.gd`），并在表中标注「来源：代码」。
> 3. **两者都没有 → 本文档新定**，标注「来源：新定」，调优期可改，但改动必须回写本文档。

## 二、状态机（实现映射）

现有原型五态 `PLAY / DRAW / DASH / BURST / REWIND` 保留，新增 `SPELL`（子弹时间施法）。GDD 3.2 状态与代码映射：

| GDD 状态 | 代码 State | 进入 | 退出 |
| --- | --- | --- | --- |
| 选向（等指针） | PLAY | 冷却/引爆结束 | 左键点击且 AP ≥ 1 |
| 斩击位移 | DASH | 左键确认 | 到达终点 |
| 停留冷却 | PLAY | 到达终点 | 玩家下次操作 |
| 子弹时间/施法 | SPELL（新） | 右键长按 | 松开右键 / TV 耗尽 |
| 回溯引爆 | REWIND → BURST | R 键或「时」字咒语 | 引爆结算完 |
| — | GAMEOVER | 计时结束 / 时滞超次 | 结算界面 |

冻结规则（沿用代码）：`DASH / BURST / REWIND` 期间敌人速度系数 0；`SPELL` 期间系数见 §5.1。

| 参数 | 值 | 来源 |

| 绑定阈值 X | **60%** | 新定 |
| 阈值换算 | 单笔笔画 ≥ 当前 TV 上限 × 60%（基础期 = 300 px）即触发绑定流程 | 新定 |

## 九、计分、结算与评级

### 9.1 计分公式（GDD 7.2 落实）

```
单杀分 = 怪物基础分（§6 表）
回溯击杀 = 单杀分 × 1.5
引爆击杀（BURST 结算时死亡）= 单杀分 × 2.0
连击：单次引爆击杀 n ≥ 2 → 加 n × 5
满屏奖励：单次引爆击杀 ≥ 10 → +200
总分 = Σ 以上 × 得分倍率
```
