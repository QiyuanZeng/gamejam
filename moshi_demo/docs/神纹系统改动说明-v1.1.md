# 神纹系统改动说明 · v1.1

基线：`c3969c9`（远端 `origin/main` 的祖先提交）。本文覆盖该基线之后、围绕「咒语 → 神纹」这条链路的全部改动。

一句话概括：**咒语系统换代为神纹录** —— 技能表从 6 条固定咒语改成「2 道古代神纹 + 6 块空碑」，释放不再收墨钱，空碑由玩家在战斗中用长笔画随机点亮并当场绑定笔形。

---

## 1. 识别内核：$Q 点云识别器

新增 `scripts/vendor/q_dollar.gd`（移植自 angrychill/q-dollar-gesture-godot，MIT）与 `scripts/spell_match.gd`。

$Q 把笔画视作点云做双向贪心最近点匹配，天然对「从哪头起笔、顺时逆时、多笔先后」免疫，只认最终落在纸上的形状；代价是丢弃行笔时序，轨迹重合而走法不同的笔形无法区分。

| 常量 | 值 | 含义 |
|---|---|---|
| `SAMPLES` | 32 | 重采样点数。比对开销随 n² 增长，32 够用且够快（实测单笔比 8 条神纹 9ms） |
| `MIN_LEN` | 120 px | 笔画长度门槛，短于此不参与任何神纹判定 |
| `SCORE_MIN` | 0.82 | 命中门槛。取自实测拒识上界 74% 与命中下界 90% 的中点 |
| `RMS_REF` | 0.35 | 得分归一基准，rms 达到此值判 0 分 |

**转正基准用「最长弦」而非 PCA 主轴**（`_chord_angle`）：汉字笔形的横竖跨度往往接近（实测特征比 0.85），主轴几乎不可辨，采样点稍有增减就能让它甩出 20°，直接把匹配打废。最长弦由两个极端点定死，稳得多。弦方向只到 π，剩下 180° 的二义靠候选侧多留一份翻转点云（`cloud_flip`）解决，比对时取更优者。

实测（`tests/qdollar_test.gd`，18 条）：

```
原形 / 平移 / 缩小 1.6× / 放大 6× / 反向书写 / 倾斜 ±15°  → 100.0%
手抖 ±6px 94.1%    反向 + 手抖 94.4%
「时」↔「雷」互认 39.8%    乱涂圆圈 17.9%    一条直线 70.6%
```

`spell_match.gd:SKILL_DEFS` 定义 8 道神纹。**古代神纹必须排在最前** —— HUD 的可绑槽列表、调试台的试录键位都锚定「可绑槽从古代神纹之后起」，调顺序要一起改。

|---|---|---|---|
| `time` | 时·回溯 | 古代 | 10s |
| `thunder` | 雷霆万钧 | 古代 | 6s |
| `quake` | 山崩地裂 | 普通 | 12s |

- **普通神纹**：空碑，战斗中由玩家的长笔画点亮并绑上那一笔的形。

## 3. 七道神纹的效果

全部参数集中在 `main.gd` §5 常量块，驻场效果各有一个 `_update_*` 收在「神纹驻场效果」段。

| 神纹 | 行为 | 关键参数 |
|---|---|---|
| 雷霆万钧 | 随机挑 6 个目标劈，每道雷连带溅射一小片 | `THUNDER_BOLTS 6` / `DMG 20` / `RADIUS 82` |
| 山崩地裂 | 6 轮地震，每 0.5s 一轮，**震源始终在玩家脚下**（跟随移动） | `QUAKE_WAVES 6` / `GAP 0.5` / `RADIUS 155` / `DMG 12` |
| 妖木精灵 | 召 4 个树人自由行动，各自扑最近的敌人 | `ENT_COUNT 4` / `LIFE 12` / `SPEED 155` / `DMG 10` |
| 水漫金山 | 八向水浪推出，每道浪对同一目标只打一次 | `FLOOD_DIRS 8` / `SPEED 540` / `RANGE 640` / `DMG 16` |
| 时间领域 | 原地领域持续掉血；玩家站在里面时钟表额外充能 | `DOMAIN_TIME 6` / `RADIUS 195` / `DPS 14` / `CHARGE 2.0` |
| 无限剑阵 | 内 6 外 12 两圈落剑，外圈起手晚 0.18s | `SWORD_R_IN 115` / `R_OUT 245` / `FALL 0.4` / `DMG 22` |

## 4. 释放规则

**释放不再收墨钱。** 时间之力只花在「描绘路径」上，画出来即生效，命中后只走冷却。`skills` 字典去掉了 `tv` 字段，HUD 技能栏、调试台判定面板同步删列。

**多个候选取最高分**（`spell_match.gd:best_match`）：笔形同时过了几道神纹的 82% 门槛时，放相似度最高的那道。该函数一次 O(n²) 比对同时返回：

- `i` —— 命中下标（没有则 -1），供释放判定用
- `top` —— 全表最高分（含冷却中与未过门槛的），供觉醒的撞形闸复用

## 5. 觉醒规则（本次改动的重点）

`main.gd:_end_draw` 的判定顺序：**先判命中，命中就释放并跳过觉醒**；没命中才轮到点亮空碑。

`_try_awaken` 五道闸全过才算觉醒：

| # | 闸 | 阈值 | 常量位置 |
|---|---|---|---|
| ① | 笔画长度 | ≥ 120 px | `spell_match.gd:MIN_LEN` |
| ② | 这一笔烧掉起笔时余额的比例（含子弹时间流逝 30/s） | ≥ 70% | `main.gd:BIND_ENERGY_RATIO` |
| ③ | 与所有已绑神纹的最高相似度 | < 70% | `spell_match.gd:BIND_MAX_SIM` |
| ④ | 还有空碑 | ≥ 1 块 | — |
| ⑤ | 掷骰 | < 50% | `main.gd:BIND_CHANCE` |

### 5.1 闸 ② 的分母修正（真 bug）

**旧口径**：`笔长 ≥ tv_max × 70%`，即固定 350 px。

**问题**：墨不满时 `_sample_ink` 会在余额耗尽处 `dry_pen` 截断笔画 —— TV 只剩 300 时最多画出 300 px，画到笔尖干涸也永远凑不到 350。**TV 不满 → 觉醒被永久关死**，越是把墨用光越触发不了。

**新口径**：新增 `draw_tv0` 在起笔时记下手头余额，门槛改成「烧掉起笔余额的 70%」。画到笔干必然 100% 达标。另补一道下限（闸 ①），防止墨快空时随手一点也算觉醒。

HUD 的觉醒线刻度随之改成动态位置：书写中按起笔余额算，平时按当前余额预演「现在起笔的话得画到哪儿」。

### 5.2 撞形闸取 70% 而非策划案的 50%

策划案原文是「与所有已触发纹路比对后相似度均小于 50%」。**这个值在 $Q 的分数尺度上卡死了整个功能。**

实测（临时诊断脚本 `shape_diag`，量完即删）：

```
觉醒线 350px · 撞形闸 50%
圆 r64      401px   时·回溯 64.3%   雷霆万钧 17.9%   → 撞形
螺旋 2 圈   392px   时·回溯 69.6%   雷霆万钧 41.3%   → 撞形
螺旋 3 圈   434px   时·回溯 69.3%   雷霆万钧 49.5%   → 撞形
五角星 r70  666px   时·回溯 62.3%   雷霆万钧 48.0%   → 撞形
三角 边150  457px   时·回溯 58.4%   雷霆万钧 31.7%   → 撞形
长 S 曲线   594px   时·回溯 54.3%   雷霆万钧 63.2%   → 撞形
梳齿 5 齿   506px   时·回溯 50.1%   雷霆万钧 55.9%   → 撞形
```

$Q 的分数基线本来就高：任何形对「时」的方框都能拿 50~70%，不是接近 0。按 50% 卡等于「没有任何形状能觉醒」。

取 **70%**：明显低于 82% 的命中门槛（留 12 点余量，不至于误判成命中），又真能放行陌生形。想回 50% 只需改 `spell_match.gd:18` 一个常量，但功能会失效。

### 5.3 绑定方式：随机绑定 + 选碑面板开关

`main.gd:bind_pick_panel`，默认 `false`：

- **关（默认）**：过闸即随机挑一块空碑绑上，**不打断战斗**，`announce` 报「神纹觉醒 · XX」。
- **开**：弹出选碑面板，战局定格（`_process` 只跑计时与重绘），按 `1~N` 选碑、`Esc` 放弃。序号照 `blank_slots()` 动态映射，不写死下标。

两条路线共用 `_bind_slot(i)`：刻上笔形 → 当场释放该技能（**觉醒那一笔本身就是一次施法**）→ 补上欠着的那次斩击（除非技能已接管状态，如「时」直接进回溯）。

### 5.4 已知问题：解锁难度随进度上升

闸 ③ 的 `top` 取的是**全表最大值**，包含古纹和已觉醒的普通纹。每多绑一个就多一次撞线机会，通过率 ≈ `(1-p)^n`：

| 已绑数 | 2（开局） | 3 | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|
| 过闸 ③（按 p=0.3 估） | 49% | 34% | 24% | 17% | 12% | 8% |

加剧因素两条：

1. 玩家的手写风格是收敛的，后画的形跟自己之前绑的形比随机形更像，实际 p 更高。
2. **冷却中的神纹也计入 `top`**（`best_match` 里 `out.top` 在冷却判断之前累加）。冷却期画一个近似形：既不释放（冷却中），又被撞形闸拦（算撞了），两头落空。

候选缓解方案（**未实施，待定**）：

| 方案 | 做法 | 代价 |
|---|---|---|
| A | 撞形闸只跟古代神纹比，普通纹交给 82% 命中闸区分 | 难度不随进度上升；两个普通纹可能形近 |
| B | 阈值随已绑数放宽 `0.70 + 0.02n`，封顶 0.80 | 平滑；仍有天花板 |
| C | 直接抬到 0.78 | 一行常量；离命中门槛只剩 4 点，误绑风险 |
| D | 连续 N 笔过闸未中则必中 | 治骰子不治闸 ③ |

## 6. 调试设施

| 键 | 功能 |
|---|---|
| `F1` / `F10` | 墨笔编辑器 |
| `F2` | 神纹调试台（`scripts/spell_lab.gd`）：左键书写 · `1/2` 选古代神纹 → 回车录入并落盘 · `E` 精修 · `C` 清空 · `R` 全部恢复默认 |
| `F3` | **一键回满时间之力**（测试用）。写到一半按也认 —— 会连带重记 `draw_tv0`，否则「烧掉起笔余额七成」的账会算成负数，觉醒反而再也过不了闸 |

调试台用无限墨书写，实时显示：笔长 / 笔墨消耗 / 子弹时间流逝 / 合计消耗 / 觉醒线位置 / 对全表 8 道神纹的逐条判定明细。

## 7. 笔形持久化

玩家在 F2 台改过的古代神纹笔形存 `user://spell_strokes.json`，扁平数组格式（`x,y,x,y…`）—— JSON 没有向量类型，来回转 Dictionary 更啰嗦也更易错。`ancient_stroke(id)` 取形时：改过就用改过的，否则回落出厂形。

## 9. 待办与风险

- **一条长直线对「雷」得分 70.6%**，恰好贴着撞形闸 —— 玩家随手一条斜长线会被当成撞形拦下不给觉醒。
- **觉醒静默失败**：骰子没中时玩家看不到任何反馈，无从分辨「没达标」与「没中」。待定是否加提示。
- **TV 数值待重估**：释放已改免费、门槛改成相对口径，580px 手写 + 子弹时间流逝的预算需要重新算一遍。
- **多笔画咒语**未支持：需要笔画分组、笔序无关匹配、HUD 多笔进度提示。
