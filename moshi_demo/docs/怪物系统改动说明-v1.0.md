# 怪物系统改动说明 v1.0

> 对应分支 `feature/rune-codex` 本轮提交。改动范围：怪物精简、精英复用、
> BOSS 移除、冲锋锁向、分裂子体无敌、数据驱动落地、波表重排、测试守门。
> 怪物配置速查见同目录 `enemies.md`。

## 1. 全场精简为 4 种怪

一套行为一只怪，一套贴图一只怪，共 **4 套素材、9 份配置**：

| 行为 | 基础怪 | 素材 | 精英版 |
|---|---|---|---|
| 近战 | `melee_mite` 影蚋 | `assets/art/enemies/shadow_mite/`（帧动画） | `elite_melee` |
| 远程 | `ranged_crystal` 晶哨 | `assets/art/enemies/crystal_sentinel/animations/` | `elite_ranged` |
| 冲锋 | `charger_fast` 疾影 | `assets/enemy_fast.png` | `elite_charger` |
| 分裂 | `splitter_bomber` 磐妖 | `assets/enemy_tank.png` | `elite_splitter` |
| └ 子体 | `splitter_bomber_shard` 磐妖碎块 | 同本体图缩至 0.6 倍 | — |

- 删除 `melee_blob.tres`（近战重复）、`elite_tank.tres`（精英用独立贴图，违规）、
  `boss_wuming.tres`（BOSS 一并移除，`_tick_boss` 代码保留为休眠骨架）。
- `melee_mite` 数值调回近战基准（hp 10 / speed 60 / 惯性关），顶替原墨魉位。

## 2. 精英怪：复用本体图 + 放大 + 发光

四份精英 `.tres` 统一倍率：放大 `1.5x`（`scale_mul` 同时放大 `tex_target` 与 `radius`）、
hp ×4、dmg ×1.8、speed ×0.85、score/coin ×3、暖金色调 `tint(1.3, 1.05, 0.75)`。

**修 bug**：精英浮金环原埋在 `_draw_body()` 里，该分支只在「无贴图也无帧动画」时执行，
四种怪全是贴图怪 → 精英此前从无特效。现抽出 `_draw_elite_glow()` 由 `_draw()`
无条件调用，贴图怪与程序绘制怪共用。

**修 bug**：`splitter_bomber` 的 `tex` 原指向不存在的 `enemy_bomber.png`，
`ResourceLoader.exists` 守卫静默回落到程序化绘制。现改用 `enemy_tank.png`。

## 3. 冲锋方向锁定

预警红线出现（进入 `windup`）的**那一帧**由 `_lock_charge_dir()` 把方向钉死，
蓄力期间不再跟随玩家转向；红线画的就是最终落点，走位可躲。
BOSS 骨架的冲锋入口同步接上。

## 4. 分裂子体出生无敌

- 新字段 `Enemy.invuln_left`，`_damage()` 与 `try_mark()` 双拦截，无敌期贴图快速闪烁。
- 时长走 `.tres` 的 `split_child_invuln`（默认 0.5 秒，填 0 即关）。
- **动机**：磐妖 `legacy_type = bomber`，死亡原地埋爆裂连锁（半径 90px），
  子体撒在爆心 34px 内，原逻辑下出生下一瞬即被自家爆炸秒杀，玩家看不到分裂发生。

## 5. 数据驱动资源化

- `EnemyData` / `EnemyDB`（`scripts/enemy_data.gd` / `enemy_db.gd`）：
  怪物配置搬至 `data/enemies/*.tres`，`to_cfg()` 保留旧键名做兼容视图，技能命中链路零改动。
- `WaveData` / `WaveDB`（`scripts/wave_data.gd` / `wave_db.gd`）：
  刷怪波表搬至 `data/waves/*.tres`，5 段按 `until_time` 排序，mix 全部换新怪 id，
  精英按阶段渐入（27s+ 后四精英齐全）。

## 6. 测试守门

- 新增 `tests/enemy_refactor_test.gd`：一行为一基础怪、全场只用 4 套素材、
  精英复用本体图、cfg 兼容键齐全、技能命中链（`_damage` / `try_mark` / `apply_mark` /
  落雷 / 击杀）逐条验证、冲锋锁向（玩家挪走方向偏差 0.000 弧度）、
  子体无敌（免疫伤害 / 挂不上标记 / 扛住父体爆炸 / 到期恢复受伤）。
- 新增 `tests/wave_live_test.gd`：波表体检、分段推进、实机刷怪、峰值 64 不越上限。
- 同步改 `smoke / spell_test / skill_fx_test` 的怪 id 引用。
- 回归：`ENEMY_REFACTOR / WAVE_LIVE / SMOKE / SPELL / SKILLFX` 五套串行全 PASS。
