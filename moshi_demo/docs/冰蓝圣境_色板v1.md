## 本轮不改

- 常规 UI 字色、技能块字色。
- 结算页排版与跳字演出结构：单独重新提视觉需求。
- 技能特效、敌人受击特效：后续单独统一蓝黑 / 蓝灰 / 雾粉红表现。
- 水面背景与角色原画：不在本轮色块替换范围内。
